# Crysta Collaboration

Crysta is a toolkit for visualizing and analyzing atomic structures, trajectories, and scalar fields. Its desktop app, command-line tools, and editor integrations share a scientific foundation written in Rust.

## Repositories

| Repository | What it provides |
| --- | --- |
| [crysta-desktop](https://github.com/Crysta-Collaboration/crysta-desktop) | Native desktop app for inspecting crystal structures, playing trajectories, and viewing scalar fields. |
| [crysta-cli](https://github.com/Crysta-Collaboration/crysta-cli) | Command-line tools for structure analysis, file conversion, and preparing electronic-structure calculation inputs. |
| [crysta-extensions](https://github.com/Crysta-Collaboration/crysta-extensions) | VS Code structure and scalar-field previews, plus a Zed task that opens saved structures in Crysta Desktop. |
| [libcrysta](https://github.com/Crysta-Collaboration/libcrysta) | Shared Rust crates for atomic structures, lattice geometry, scientific file formats, and GPU rendering. |

Repository links require GitHub access to the corresponding project.
